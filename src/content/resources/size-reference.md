# 尺寸参考表

## 床下高度对照

| 床架类型 | 床高 | 能塞收纳箱高度 | 备注 |
|---------|------|----------------|------|
| 标准木床架 | 45cm | ≤ 35cm | 根据垫厚度调整 |
| 低矮床架 | 30cm | ≤ 20cm | 收纳空间有限 |
| 高架床 | 65cm | ≤ 50cm | 推荐放置空间最大 |

## 衣柜挂杆高度

- 长衣区（大衣、连衣裙）：140-170cm
- 短衣区（裤子、上衣）：60-90cm
- 标准配置：150cm（深层）+ 75cm（浅层）

## 食品柜深度实测

- 标准深度：35-40cm
- 我家深柜：30cm（特殊尺寸）
